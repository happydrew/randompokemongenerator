# Privacy Policy for Intitle Quick Search

**Effective date:** June 3, 2026

Intitle Quick Search ("the extension") respects your privacy. This Privacy Policy explains what information the extension accesses, how it is used, and what choices you have.

## 1. Summary

The extension is designed to help users quickly perform keyword research actions from selected text in the browser, including Google `intitle:` search, standard Google search, Google Trends search, keyword copying, and optional keyword translation.

The extension does **not** sell personal data.  
The extension does **not** collect browsing history for analytics or advertising.  
The extension does **not** run a backend server operated by the developer for storing user data.

## 2. Information the extension accesses

The extension may access the following information only to provide its core functionality:

### a. User-selected text

When you select text on a webpage and trigger the extension, the extension accesses that selected text in order to:

- build a Google `intitle:` search query,
- build a standard Google search query,
- build a Google Trends query,
- copy keywords to your clipboard when you choose to do so,
- translate keywords when translation is enabled.

### b. Page content on supported pages

On supported pages, the extension may read visible keyword text from the page in order to:

- copy top keywords,
- display translated keyword labels next to keywords.

### c. User settings

The extension stores your settings, such as:

- custom keyword pattern,
- whether to open results in a background tab,
- whether to copy keywords automatically,
- whether keyword translation is enabled,
- translation provider and target language.

### d. Local translation cache

To reduce repeated translation requests, the extension stores a local cache of translated keywords.

## 3. How information is used

The extension uses accessed information only to provide the features you request.

Specifically:

- selected text is used to create searches you intentionally trigger,
- keyword text may be sent to Google Translate only when translation is enabled,
- settings are stored so the extension behaves according to your preferences,
- cached translations are stored locally to improve speed and reduce repeated requests.

## 4. Data sharing

The extension does not share your data with the developer or third-party advertisers.

The extension may send data to third-party services only when required for the feature you use:

### a. Google Search

If you trigger a search, the selected keyword is included in the Google search URL opened in your browser.

### b. Google Trends

If you trigger a Google Trends search, the selected keyword is included in the Google Trends URL opened in your browser.

### c. Google Translate

If you enable keyword translation, keyword text that needs translation may be sent to:

- `https://translate.googleapis.com/*`

This is used only to return translated text for display inside the extension workflow.

## 5. Data storage

The extension uses Chrome storage APIs to store:

- synced settings (`chrome.storage.sync`),
- local translation cache (`chrome.storage.local`).

The developer does not operate a remote database for storing this information.

## 6. What the extension does not do

The extension does not:

- sell personal information,
- use data for advertising,
- collect payment information,
- record passwords,
- collect personal messages,
- transmit full webpage content to the developer,
- store your browsing history on developer-controlled servers.

## 7. User control

You can control the extension by:

- changing or disabling features in the extension popup,
- disabling keyword translation,
- removing the extension at any time,
- clearing extension data through your browser's extension settings.

## 8. Security

The extension is designed to minimize data use and keep data in the browser where possible. However, no method of software operation or internet transmission is completely secure.

## 9. Changes to this policy

This Privacy Policy may be updated from time to time. If the policy changes, the updated version will be made available at the extension's published policy URL, with a revised effective date.
