## How the Extension Works

The Random Pokemon Generator is a **simple randomization tool** that:

1. **Displays Static Pokemon Data**: All Pokemon information (1,350+ Pokemon names and IDs) is embedded directly in the extension code
2. **Local Operation**: Random Pokemon selection happens entirely on your local device with no data transmission
3. **No User Data Storage**: The extension does not store any information about your Pokemon selections, preferences, or usage patterns
4. **Popup Only**: The extension only provides a popup interface when you click the extension icon - it does not inject any code into websites you visit
5. **External Images**: Pokemon images are loaded from our official website (randompokegen.cc) for display purposes only

## External Resources

The extension loads Pokemon images from:
- **Source**: https://randompokegen.cc/img/sprites/
- **Purpose**: Display high-quality Pokemon artwork
- **Privacy**: These image requests do not include any personal information or tracking data
- **Note**: Standard web server logs may record image requests (IP address, timestamp) as with any website image load, but this data is not used for tracking or profiling
