# Random Pokemon Generator

## Project Overview
Random Pokemon Generator is a comprehensive web application that allows users to generate random Pokémon based on a wide variety of customizable filters. The official site is deployed at [randompokegen.cc](https://randompokegen.cc).

## Key Features
- **Extensive Filtering Options**: Users can filter Pokémon by:
  - Generation, Region, Type, Forms, Rarity
  - Height, Weight, Colors, Evolution Stage
  - Baby Pokémon, Growth Rate, Habitats, Egg Group
  - Gender Rate, Shape, Default Form, Gender Differences
  - Base Stats (HP, Attack, Defense, Special Attack, Special Defense, Speed)
  - IVs, EVs, Base Happiness, Capture Rate, Hatch Counter
  - Game Versions

- **Shiny Pokémon Generation**: Users can generate shiny Pokémon with adjustable probability settings.

- **High-Definition Visuals**: Displays Pokémon using high-quality artwork and sprites.

- **Card Display System**: Each generated Pokémon is shown on a beautifully designed card that includes detailed information.

- **History View & Management**: Up to 64 generations are saved for revisiting favorite Pokémon cards.

- **Mobile-Optimized Interface**: Fully responsive design that works well on smartphones, tablets, and desktops.

## Core Features Explained
1. **Random Generation**: The application uses a sophisticated algorithm to randomly select Pokémon that match all specified filter criteria.

2. **Filtering System**: The extensive filtering options allow users to narrow down Pokémon selection based on almost any characteristic.

3. **Display Customization**: Users can choose which attributes to display on the Pokémon cards, including abilities, stats, and more.

4. **Shiny Collection**: A special section tracks and displays any shiny Pokémon that are generated.

5. **History Management**: Users can review previously generated Pokémon and adjust settings as needed.
